# Sound effects

This folder is the target location for approved audio files transferred
from the `SFX` source branch.

The source branch currently contains `voidattack.wav`, plus `SFXRules.md`.
Follow the source branch's audio rules: no NSFW sounds, use content with
appropriate reuse rights, and keep sounds relevant to Card Stuff Yes.

The source branch is being preserved until the binary audio is copied and
its app references are checked.
