# Card artwork

This folder is the target location for approved card image files transferred
from the `Cards` source branch.

The source branch currently contains `s1-01.png`, `S1-02.png`, and
`S1-03.png`, plus `CardRules.md`. The original branch is being preserved
until the binary files are copied and the app's image paths are updated and
tested.

Follow the upload permissions and rules in the source branch's
`CardRules.md`. Do not replace or rename card files as part of a bulk move
without checking references in the app.
